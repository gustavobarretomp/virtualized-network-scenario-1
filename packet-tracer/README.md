# 🌐 Cisco Packet Tracer - Network Topology

## 📌 Descrição

Projeto de simulação de uma infraestrutura de rede utilizando **Cisco Packet Tracer**, com implementação de roteamento dinâmico e serviços de rede.

A topologia foi desenvolvida para representar a comunicação entre diferentes redes através de equipamentos Cisco.

---

## 🖥️ Estrutura da Rede

- 5x Roteadores Cisco
- 5x Switches
- 3x Computadores
- 3x Servidores HTTP
- 2x Servidores DNS

---

## ⚙️ Configurações Implementadas

- Roteamento dinâmico utilizando **RIPv2**
- Configuração de endereçamento IPv4
- Comunicação entre diferentes redes
- Implementação de serviços HTTP e DNS
- Configuração de dispositivos Cisco

---

## 🛠️ Ferramentas

- Cisco Packet Tracer
- Cisco IOS
- IPv4
- RIPv2
- DNS
- HTTP

---

## 📁 Arquivo do Projeto

Arquivo principal:

```
network_topology.pkt
```

Abra o arquivo utilizando o **Cisco Packet Tracer** para visualizar a topologia e as configurações.
